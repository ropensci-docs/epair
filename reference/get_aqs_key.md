# Get an API key from the AQS API.

Get an API key from the AQS API.

## Usage

``` r
get_aqs_key(user.email)
```

## Arguments

- user.email:

  Email provided by the user to get an API key for.

## Examples

``` r
if (FALSE) { # \dontrun{
email <- "an.example.email@domain.com"
get_aqs_key(email)
} # }
```
