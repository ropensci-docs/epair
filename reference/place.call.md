# Place the URL as a call to the EPA API

Place the URL as a call to the EPA API

## Usage

``` r
place.call(url)
```

## Arguments

- url:

  A string with a valid URL for the EPA API

## Value

Result of query from the API

## Examples

``` r
if (FALSE) { # \dontrun{
url <- "user_url"
result <- place.call(url)
} # }
```
