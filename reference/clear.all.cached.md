# Removes all cached memory of perform.call

Removes all cached memory of perform.call

## Usage

``` r
clear.all.cached(directory = "/cache")
```

## Arguments

- directory:

  Place inside user-level cache directory that was used to store the
  cached data previously. Default: "/cache".

## Value

'Done' if data was successfully forgotten, error message if cache
directory was not found

## Examples

``` r
if (FALSE) { # \dontrun{
clear.all.cached() 
} # }
```
